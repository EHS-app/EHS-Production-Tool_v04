Session Plan:
# Objective

Three new features on the LED Screen Report tab:

1. Manual name-pill size — let the producer scale the centred screen-name pill on the visual (and the exported PNG) without editing settings globally.
2. Power & signal markers — let the producer drop labelled P1/P2/S1/S2 markers on each screen visual to show the crew where to land power and signal cables. Drag to move, alt-click / right-click to delete, "Clear" to reset.
3. Auto-attach LED diagrams — when the producer hits "Share with Crew", generate one PNG per LED screen (with markers + scaled pill) and attach them to every brief link alongside the floor plan, so the crew can download them from the portal.

# Tasks

### T001: Data model
- Blocked By: []
- Details:

  - Add optional nameScale: number (default 1) and markers: LedScreenMarker[] (default []) to LedScreen and LedLinkedMeta.
  - Update newLedScreen and defaultLinkedLedMeta to seed defaults.
  - Add helpers clampNameScale, nextMarkerIndex(markers, kind).
  - Acceptance: typecheck passes; existing persisted LedScreen blobs still load (defaults applied).

### T002: Live preview interactions
- Blocked By: [T001]
- Details:
  - LedScreenReportView.tsx:
    - Lift state placeMode: { screenId, kind } | null + handlers in the parent.
    - In ScreenSvg, render every marker as a coloured circle + label (red for power, blue for signal). Apply screen.nameScale ?? 1 to the pill font.
    - Click on the screen rect while in placeMode for THIS screen -> emit an add-marker call with normalised coords; mode clears.
    - Pointer-down on a marker -> start drag; pointer-move updates coords via getScreenCTM().inverse(); pointer-up persists. Use setPointerCapture so the drag survives leaving the SVG element.
    - Alt-click or contextmenu on a marker -> delete.
  - Acceptance: producer can click "+P" in a row, click on the screen visual, and a P1 dot appears that can be dragged.

  - Acceptance: controls visible per row; place-mode indicator (cursor changes / visible toolbar hint) clear.
